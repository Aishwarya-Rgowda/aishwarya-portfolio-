# Aishwarya — Portfolio Website

A responsive, single-page student portfolio website.

## Publish with GitHub Pages (phone-friendly)
1. Sign in to GitHub and create a **new public repository** named `aishwarya-portfolio`.
2. Choose **Add file → Upload files** and upload `index.html` from this folder.
3. Commit the file to the `main` branch.
4. Open the repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
6. Wait a few minutes. Your website should appear at:
   `https://aishwarya-rgowda.github.io/aishwarya-portfolio/`

Check the generated URL in GitHub Pages before submitting it. This repository name is a suggestion; the final URL depends on the account and repository settings.
